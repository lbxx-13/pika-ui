# 轻量 UX 走查

当页面存在主要操作流程时读取。评审者应从实际页面推断用户目标并尝试完成，不依赖预设的理想路径。

## 走查步骤

1. 从页面当前状态判断用户要完成的事，并找到入口。
2. 完成一条主要路径，观察每一步的选择、反馈和下一步线索。
3. 检查一个最重要的错误/恢复或空内容场景。
4. 检查结果是否可见、可理解、可继续；如果会保存，刷新后确认结果仍在。
5. 在代表性窄屏检查触控目标、阅读顺序、键盘遮挡和返回路径。

## 报告格式

按优先级列出可复现的问题。每条写页面/步骤、实际行为、用户影响和具体建议。没有亲自操作的内容标注为推断。只做 UX 评审时不直接修改实现；修复由用户或后续任务决定。
