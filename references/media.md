# 素材与来源

先用用户提供和项目已有的图片、插画、图标、视频与字体。素材需要承担内容说明、产品证据或方向表达中的一项；没有视觉作用时不要为了填空强加配图。

- 方向依赖特定主视觉时，先确定素材来源和比例，再围绕它安排布局。不要把主图留到页面填满后才补。
- 需要外部素材时，核对来源、使用许可、署名要求、分辨率、裁切方式和本地项目的资源规范。许可不清时只用作参考，不直接交付。
- 使用生成图时检查生成内容是否误导为真实商品、客户或数据；真实业务对象应优先用可信的项目素材。
- 同一页面的插图应有一致的镜头、光照、材质和色彩逻辑。将素材放入界面后再检查对比度、裁切和背景适配。
- 图标使用项目现有图标库；不要用表情符号替代功能图标，不要把通用图标画成角色或产品主视觉。
- 交付时标注新增素材、来源/生成方式和未完成的素材位。
