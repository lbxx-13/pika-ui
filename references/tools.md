# 浏览器与本地工具

先检查项目实际的包管理器和启动命令，沿用项目工具；不要因为 skill 自带了比较页就引入新的测试框架或截图依赖。

- **打开页面：** 优先使用当前宿主已有的浏览器/预览工具。启动本地服务时按项目说明操作，使用实际路由和状态。
- **截图：** 截用户目标视口与本次改动相关状态。截图是证据载体，必须实际查看；若无法截图或看图，明确写出限制。
- **并排比较：** 先准备独立可打开的 HTML 或本地服务候选，再按 [方向比较器说明](style-explorer.md) 生成比较页。
- **交互走查：** 按 [UX 走查](ux-review.md) 操作实际页面；图片或静态 mockup 不能证明交互可用。
- **过程文件：** 截图、候选页和临时素材放在项目约定的临时/输出目录，不放进 skill 安装目录，也不要误提交到产品资源。
- **交付证据：** 记录检查过的视口、状态和主要结果；没有跑过的流程不写成通过。
